# BE-101 — Бэкенд для смежных специальностей

Интерактивный курс для фронтендеров, QA-инженеров и аналитиков продуктовой команды:
учимся понимать бэкенд и писать код на стеке **Spring Boot, Hibernate, Kafka, Lombok, MapStruct**.

## Как открыть курс

Курс — статический сайт, сервер не нужен:

1. Склонируй репозиторий
2. Открой файл `site/index.html` двойным кликом в браузере

Прогресс хранится локально в твоём браузере (localStorage) — никуда не отправляется.

## Как учиться

- Уроки читаются в любом порядке, но лучше по порядку 🙂
- После каждого урока — квиз: отвечаешь, сразу видишь пояснение «почему»
- Урок считается пройденным (✓), когда квиз сдан на **80%+**. Пересдавать можно сколько угодно
- К некоторым урокам прилагается **лабораторная** — настоящий код в этом же репозитории

## Как делать лабораторные

Лабы живут в ветках репозитория. На каждую лабу — пара веток:

| Ветка | Что внутри |
|---|---|
| `lab-N` | Скелет проекта с TODO-метками — здесь ты пишешь код |
| `lab-N-solution` | Эталонное решение — открой после того, как сделал сам |

Порядок действий:

```bash
git checkout lab-1        # переключиться на ветку с заданием
# ... пишешь код ...
mvn test                  # проверка (для лаб с автотестами)
```

Когда закончил — открой файлы из `lab-N-solution` в IDE и сравни со своим решением.
Ничего никуда пушить не нужно, всё локально.

> Подробная инструкция «как переключать ветки» — в тексте первой лабы.

## Структура репозитория

```
content/            # уроки курса (markdown + квизы)
  module-1/         # «Spring Boot: бэкенд с нуля»
site/               # сгенерированный сайт курса (открывать site/index.html)
tools/generator/    # генератор статики из markdown
```

## Пересобрать сайт после правки уроков

```bash
cd tools/generator
npm install         # один раз
npm run build       # пересоберёт site/
```

## Разработка (для мейнтейнеров)

Интеграционная ветка — `develop`: каждый урок делается в отдельной ветке
(`lesson-02`, `lesson-03`, …) и мержится в `develop` после готовности.

```bash
git checkout develop
git checkout -b lesson-02
# … пишем content/module-1/lesson-02.md, npm run build …
git checkout develop
git merge lesson-02
```

После правки уроков пересобери сайт: `cd tools/generator && npm run build` —
и закоммить обновлённый `site/` вместе с контентом.

Ветки лаб (`lab-N`, `lab-N-solution`) в мерж-процесс не входят — это
задания для студентов, они живут отдельно.
