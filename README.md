# Лаба 0. Запуск (после урока 2)

Цель этой лабы — **не сломать ничего не сломав**: поставить окружение и запустить
уже готовое приложение. Здесь не нужно писать код. Если в конце `mvn test` зелёный,
а `/api/ping` отвечает в браузере — вы готовы ко всему курсу.

## Шаг 1. Поставь JDK 21

JDK — это «движок», на котором работает Java (аналог Node.js для JavaScript).

1. Скачай **Eclipse Temurin JDK 21**: <https://adoptium.net/temurin/releases/?version=21>
   (выбери свою ОС, файл `.pkg` / `.msi`).
2. Установи.
3. Проверь в терминале:

```bash
java -version
```

Должно быть что-то вроде `openjdk version "21.x.x"`. Подходит и более новая версия (25).

> Windows: если команда не находится — перезапусти терминал после установки.

## Шаг 2. Поставь IDE

Нужна **IntelliJ IDEA Community Edition** (бесплатная): <https://www.jetbrains.com/idea/download/>
(листай вниз до Community). При первом запуске выбери «Open» — и укажи папку этого проекта.

IDEA сама предложит скачать Maven — соглашайся (Maven — «npm для Java»: качает зависимости
и запускает сборку; в терминале он тоже есть: `mvn -version`).

## Шаг 3. Переключись на ветку с заданием

Лабы живут в ветках git. Сейчас ты, скорее всего, на ветке `develop` (там сайт курса).
Переключить ветку = сказать git «покажи мне файлы другой ветки»:

```bash
git checkout lab-0
```

Как это выглядит:

```
develop ────●────●────●          ← сайт курса (ты пришёл отсюда)
                     \
                      lab-0 ─── ← файлы этой лабы (ты здесь сейчас)

git checkout lab-0     → прыжок на ветку lab-0
git checkout develop   → вернуться обратно к курсу
```

> Ничего не «отправляется» и не теряется: все ветки лежат в твоём локальном клоне.

## Шаг 4. Запусти тесты

В терминале (из папки проекта):

```bash
mvn test
```

Первая сборка скачает зависимости — это нормально, несколько минут. В конце ищи:

```
[INFO] BUILD SUCCESS
[INFO] Tests run: 2, Failures: 0, Errors: 0, Skipped: 0
```

В IDEA то же самое: правый клик по папке `src/test` → `Run 'All Tests'` — зелёные галочки.

## Шаг 5. Запусти приложение

```bash
mvn spring-boot:run
```

Дождись строки про запуск, затем открой в браузере:

- <http://localhost:8080/api/ping> — твой первый живой endpoint 🎉
- <http://localhost:8080/actuator/health> — бонус: health-check из урока 5

Или через curl:

```bash
curl http://localhost:8080/api/ping
```

Остановить приложение: `Ctrl+C` в терминале.
