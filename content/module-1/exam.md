# Экзамен модуля «Spring Boot: бэкенд с нуля»

Вы прошли пять уроков: HTTP, устройство сервиса, Java-шпаргалка, REST-контроллер, слои с Kafka и наблюдаемостью. Финальная проверка — в двух частях:

1. **Кейс** — спроектировать API своими словами (сначала пишете своё решение, потом сверяетесь с эталоном)
2. **Экзамен** — 18 вопросов по всему модулю, порог 80%, пересдача не ограничена

Сначала кейс, потом экзамен. Поехали.

## Кейс

```case
title: "Спроектируй API для списка задач"
task: "Команда хочет внутренний таск-трекер. Известно: есть проекты; в проекте — задачи; у задачи — название, дедлайн и признак «сделано». Фронтендер просит: «скажи, что вызывать». Опиши API: какие endpoints (метод + путь), какие статусы ждать, как выглядят основные DTO. Форма свободная — как писали бы в чате команды. Подсказка: вспомните урок 1 (методы и статусы) и урок 4 (DTO и коды создания)."
placeholder: "Например:\nGET /api/projects — список проектов\nPOST /api/tasks — создать задачу, 201 + ..."
reference: |
  Один из возможных ответов (не единственно верный — важна логика).

  ## Endpoints

  | Метод и путь | Что делает | Успех |
  |---|---|---|
  | `GET /api/projects` | Список проектов | `200` + `[{id, title}]` |
  | `POST /api/projects` | Создать проект | `201` + `Location: /api/projects/{id}` |
  | `GET /api/projects/{id}/tasks` | Задачи проекта (можно фильтр `?status=done`) | `200` + список |
  | `POST /api/projects/{id}/tasks` | Создать задачу в проекте | `201` + `Location` |
  | `PATCH /api/tasks/{id}` | Частичное изменение: «сделано», дедлайн | `200` |
  | `DELETE /api/tasks/{id}` | Удалить задачу | `204` (без тела) |

  ## Ключевые решения

  - **PATCH, а не PUT** для «сделано»: меняем одно поле, а не всю задачу целиком.
  - **201 + Location** при создании — сервер говорит, где лежит новое (урок 1).
  - **204 без тела** при удалении — удалять больше нечего, рассказывать нечего.
  - Ошибки: `400` — кривой JSON/валидация, `404` — проекта или задачи нет.

  ## DTO

      record TaskResponse(Long id, String title, LocalDate deadline, boolean done)
      record CreateTaskRequest(String title, LocalDate deadline)

  Внутри — entity `Task` с `@Entity`; наружу — DTO без лишних полей (урок 4). Между ними — MapStruct.

  ## Продвинутый уровень (не обязателен)

  Пометка «сделано» — событие `tasks.completed` в Kafka: уведомления и статистика дочитают сами, а API не ждёт рассылки писем (урок 5). Метрику `tasks.completed.total` через Micrometer — и на дашборд.
```
